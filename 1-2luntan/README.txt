江城大学校园论坛｜1-2 场景网页
================================

学校名称：
- 剧本中绝大多数场次统一写作“江城大学”，简称“江大”。
- 末段出现一次“江州大学”，与全文设定不一致，制作中已按“江城大学”统一。

推荐拍摄方式：
1. 解压整个文件夹。
2. 双击“剧情演示页.html”：
   - 首页先停留约 0.9 秒；
   - 顶部弹出目标帖通知；
   - 点击通知进入帖子；
   - 进入后自动定位评论区，评论会持续快速刷新。
3. 也可直接双击“帖子拍摄页.html”，直接进入目标帖子评论区。
4. “index.html”是论坛完整首页，可手动点击目标热帖进入。

页面层级：
- 论坛首页：index.html
- 江大生活版块：board.html
- 目标爆料帖：thread.html
- 剧情自动演示：scene.html
- 楼主主页：user.html
- 消息中心：notices.html
- 搜索结果：search.html

使用说明：
- 所有页面均为纯静态文件，不需要联网。
- 手机、平板和电脑浏览器均可打开。
- 若浏览器限制本地文件跳转，可运行“本地启动.bat”，再打开提示的网址。
- 拍摄时建议浏览器缩放保持 100%，手机竖屏使用。
